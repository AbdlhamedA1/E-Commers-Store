# 🌸 متجر أركان (Arkan Store) – النسخة التجريبية (Demo)

موقع متجر إلكتروني تجريبي لبراند **أركان** لمستحضرات التجميل والعناية الشخصية للبنات، مصمم خصيصاً ليعرض على العميل لمشاهدة الهوية البصرية، واجهة المستخدم وتجربة الطلب السلسة عبر واتساب.

---

## ✨ المميزات الرئيسية

- **واجهة أنثوية فاخرة وناعمة (Soft Luxury):** درجات الوردي والأبيض والروز جولد مع خط Cairo العربي الأنيق.
- **تصميم Mobile First كامل وRTL:** تجربة تصفح مثالية وسلسة على الموبايل والتابلت والديسكتوب.
- **إتمام الطلب عبر واتساب:** بدون تعقيدات الدفع الإلكتروني، يتم بناء رسالة طلب منسقة تلقائياً بأسماء المنتجات والكميات والأسعار والإجمالي وبيانات العميل.
- **سلة مشتريات ذكية ومحفوظة:** تخزين في `localStorage` يحفظ المنتجات حتى بعد تحديث الصفحة أو إغلاق المتصفح.
- **إدارة المخزون:** منع العميل من تخطي الكمية المتاحة بالمخزون، مع إشارات بصرية للحالات الخاصة ("كمية محدودة" و"نفدت الكمية").
- **بحث وفلترة وترتيب لحظي:** بحث مع Debounce وفلترة حسب القسم، السعر، المخزون، والترتيب (الأحدث، الأقل سعراً، الأكثر خصماً).
- **قائمة المفضلة (Wishlist):** إمكانية حفظ المنتجات المفضلة والرجوع إليها.
- **عرض سريع (Quick View):** معاينة سريعة وتفاصيل وصور المنتج من داخل الصفحة الرئيسية أو المتجر بدون مغادرتها.
- **كوبونات الخصم:** كود تجريبي (`ARKAN10`) يطبق خصم 10% فورياً ويظهر بالرسالة الموجهة للواتساب.

## 🚀 طريقة التثبيت والتشغيل محلياً

1. تأكد من تثبيت **Node.js** (إصدار 18 أو أحدث).
2. ثبّت حزم المشروع:
   ```bash
   npm install
   ```
3. شغّل خادم التطوير:
   ```bash
   npm run dev
   ```
   افتح الرابط الظاهر في المتصفح (عادة: `http://localhost:5173`).

4. لبناء نسخة الإنتاج الجاهزة للنشر:
   ```bash
   npm run build
   ```

## 💄 كيفية إضافة منتج جديد

بيانات المنتجات موجودة في ملف:  
👉 **`src/data/products.json`**

لإضافة منتج جديد، أضيفي كائن جديد في المصفوفة بالشكل التالي:

```json
{
  "id": 21,
  "name": "اسم المنتج الجديد",
  "category": "مكياج",
  "price": 180,
  "oldPrice": 220,
  "stock": 10,
  "image": "رابط_الصورة_الرئيسية.jpg",
  "images": [
    "رابط_الصورة_الرئيسية.jpg",
    "رابط_صورة_إضافية.jpg"
  ],
  "description": "وصف جذاب للمنتج وطريقة استخدامه.",
  "isNew": true,
  "isBestSeller": false,
  "rating": 4.9,
  "reviewsCount": 15
}
```

> **ملاحظات حول الحقول:**
> - `category`: اختر أحد الأقسام: "مكياج"، "عناية بالبشرة"، "عناية بالشعر"، "عطور"، "إكسسوارات"، "أدوات شخصية".
> - `stock`: إذا كان `0` سيظهر المنتج كـ "نفدت الكمية" ويتعطل زر الشراء تلقائياً. وإذا كان بين `1` و `5` ستظهر شارة "كمية محدودة 🔥".
> - `oldPrice`: ضعي السعر قبل الخصم ليظهر مشطوباً مع شارة الخصم `-XX%`، أو اتركيه `null` لو مفيش خصم.

## 📝 كيفية إضافة مقال جديد للمدونة

المقالات موجودة في ملف:  
👉 **`src/data/posts.json`**

يمكنك إضافة مقال جديد يحتوي على:
- `id`, `title`, `excerpt`, `date`, `readTime`, `category`, `image`, و `content` (مصفوفة فقرات).

## 🎨 تغيير ألوان الثيم (Tailwind)

الألوان محددة في:  
👉 **`tailwind.config.js`**

يمكن تعديل التدرجات الوردية الأساسية من كائن `colors.brand` أو تدرجات `rosegold`.

## 🌐 النشر أونلاين للعميل (Deployment)

يمكن رفع المشروع بضغطة زر على منصات مثل:
